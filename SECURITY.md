# Security Policy

Thank you for helping keep Artto secure.

This project is maintained as a controlled, non-commercial project. Security issues must be handled through the official project process and not through public exploitation or public disclosure.

## Reporting a vulnerability

If you discover a security issue, please report it privately to the project owner or maintainer.

Do not:
- publish the issue publicly before it is reviewed,
- exploit the issue for personal or commercial gain,
- use the issue to claim ownership or rights over the project,
- redistribute the vulnerable code or build.

## Responsible disclosure

Please provide as much detail as possible, including:
- the affected component,
- the nature of the vulnerability,
- steps to reproduce it,
- impact and severity,
- suggested mitigation if available.

We will review the report and respond as quickly as possible.

## Project handling

This project is not intended for external commercial use, unofficial forks, or independent distribution. Any security issue must be addressed within the official project workflow, under the project owner’s authority, and in accordance with the project contribution policy.

## Contribution safety

Contributors must not open a pull request containing an undisclosed vulnerability or exploit. Any such issue must be reported privately before it is discussed in public channels and before any public contribution is made.

## No warranty

This project is provided "AS IS" and is not guaranteed to be free of vulnerabilities. The project owner reserves the right to review, fix, or reject any report according to project policy.
