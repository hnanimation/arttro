# Contributing to Artto

Thank you for your interest in contributing to Artto.

This project is currently maintained as a contribution-only project. Contributions are welcome only through the official project repository and only under the project owner’s review and approval.

## Contribution rules

- Contributions must be submitted through the official project repository.
- Do not fork this project and publish it as your own separate product.
- Do not use this project for commercial purposes.
- Do not copy code or assets into another project without written permission.
- Any contribution becomes part of the official project and remains subject to the project owner’s rights.

## What can be contributed

You may contribute:
- bug fixes
- UI improvements
- code cleanup
- documentation updates
- issue reports
- feature ideas

## Contribution process

1. Open an issue or discuss the idea with the project maintainer.
2. Wait for approval before starting major work.
3. Submit a clean pull request to the official repository.
4. Keep commits focused and clearly described.
5. Do not create independent releases, forks, or derivative products.

## Ownership

By contributing to this project, you agree that:
- the project owner retains full ownership of the project,
- your contribution is submitted for review and may be accepted or rejected,
- you may not claim ownership or commercial rights over the project or its codebase.

## Final note

This project is protected to keep it non-commercial and contribution-controlled. Contributions are welcome only within the project’s official process.
